## What's new in v0.2.2

A fix release for this personal fork of
[v1k0d3n/monoink](https://github.com/v1k0d3n/monoink).

### Fixed
- **The plugin loads again on current Steam clients.** v0.2.1 failed to
  load with `TypeError: SteamClient.System.Regi…` on Steam versions that
  no longer have the suspend notice it listened for. The plugin now only
  listens for the Steam notices that exist, and uses Steam's newer suspend
  and resume notices where the old ones are gone. If neither exists, the
  suspend screen is still drawn when the system suspends, as before v0.2.1.

### Development
- Panel tests (`pnpm test`) run the Steam notice relay against old, new,
  empty and failing Steam APIs, in CI and `package.sh`.
