## What's new in v0.2.1

A fix release for this personal fork of
[v1k0d3n/monoink](https://github.com/v1k0d3n/monoink).

### Fixed
- **"Now playing" switches to "Last played" as soon as a game closes**,
  even when the Game screen is already up (for example with **Always
  Game**). The plugin now passes on Steam's own notice that a game stopped,
  instead of waiting for the game's processes to finish exiting. "Last
  played" shows the game you just closed.
- **The suspend screen gets to the display in time.** It starts as soon as
  Steam asks to suspend, a few seconds before the system does. A game still
  running when the device suspends or shuts down shows as last played.

### Documentation
- The privacy page lists the Steam notices the plugin passes to the
  service: a game starting or stopping (its app number), and suspend and
  resume.
